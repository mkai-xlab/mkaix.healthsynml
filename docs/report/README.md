# Experiment Reports

This folder contains the retained experiment evidence. Notebooks live in [`notebooks/`](../../notebooks/); report links point there rather than storing duplicate notebook copies. Historical per-run figures and README files live under [`archive/`](archive/) so the main report areas stay small.

| Area | Use | Main files |
| --- | --- | --- |
| DenseNet-121 | Human-readable experiment history and archived run assets | [report](dense_net_121/report.md), [run index](dense_net_121/experiment_summary.csv) |
| SE-ResNeXt-50 32x4d | Human-readable experiment history and archived run assets | [report](se_resnext50_32x4d/report.md), [run index](se_resnext50_32x4d/experiment_summary.csv) |
| Cross-model summary | Consolidated, spreadsheet-friendly records | [workbook](all_experiments.xlsx), [model summary](model_experiment_summary.csv), [overview](summary/overview.csv) |

Use the model report for conclusions and the CSV files when filtering or comparing configurations. Open [`archive/`](archive/) only when you need a run's original figures or per-run README.
