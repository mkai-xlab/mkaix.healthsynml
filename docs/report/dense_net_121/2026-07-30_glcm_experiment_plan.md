# Production-Aligned GLCM Fusion Experiment Plan

**Prepared:** 2026-07-30  
**Status:** Proposal only; no training or test-set evaluation has been performed  
**Primary model:** DenseNet-121, five-class cross-entropy  
**Primary question:** Does a compact GLCM texture branch improve five-grade KL
classification on production-aligned knee ROIs without weakening explanation
faithfulness, anatomical localization, or calibration?

## Decision

Run a controlled two-arm experiment only after the production-ROI robustness
work establishes a reproducible baseline. Compare the selected DenseNet-121
configuration with an otherwise identical model that adds six standardized
GLCM features through an additive class-logit branch.

Do not add EfficientNet-B7, change the loss, alter the imbalance strategy, or
exclude KL-1 in this experiment. Those changes would prevent attribution of the
result to GLCM.

The experiment is validation-only during development. The repeatedly inspected
test split must not be used to select the GLCM configuration, feature parameters,
fusion weight, checkpoint, or acceptance thresholds.

## Production-ROI Prerequisite

Both arms must consume ROIs generated by the exact deployed path:

- the same YOLO checkpoint and confidence threshold;
- the same bounding-box expansion and `make_square_roi` policy;
- no center crop and no removal of medial or lateral osteophyte margins;
- the same black padding behavior;
- LAB-space CLAHE with clip limit `1.25`;
- direct resize to `384 x 384`;
- ImageNet normalization;
- the same laterality behavior as the selected production checkpoint.

The split must be patient-disjoint. Both knees from one patient must remain in
the same partition. Exact-image hash deduplication is necessary but is not a
substitute for patient-level grouping.

If the production-ROI robustness experiment selects a preprocessing or geometry
configuration different from the current API path, pin that selected
configuration before starting this experiment and use it unchanged in both arms.

## Experiment Arms

| Arm | Configuration | Purpose |
| --- | --- | --- |
| `A_deep_control` | Selected production-aligned DenseNet-121, five-class CE, existing sampler, no GLCM | Establish the paired control |
| `B_deep_glcm_additive` | Arm A plus standardized six-feature GLCM branch and additive class logits | Measure the isolated value of texture fusion |

Use at least three fixed seeds. Every seed must use the same patient groups in
both arms. Data order and augmentation RNG may vary by seed, but the paired arms
must share the seed.

## Fixed Training Conditions

The following settings must be identical across the two arms:

- ImageNet initialization;
- train/validation partitions;
- full five-class labels `0, 1, 2, 3, 4`;
- cross-entropy objective;
- exactly one imbalance mechanism;
- augmentation probabilities and parameters;
- optimizer, discriminative learning rates, weight decay, and scheduler;
- staged freezing or unfreezing schedule;
- batch size, epoch budget, early stopping, and gradient clipping;
- checkpoint-selection formula;
- CAM target layer and CAM rendering inputs.

Do not combine the full inverse-frequency sampler with class-weighted CE. If the
production baseline retains the sampler, both experiment arms must retain the
same sampler and use unweighted CE.

## GLCM Input and Extraction

Generate GLCM features from the deterministic CLAHE-enhanced grayscale ROI
before ImageNet normalization. Do not compute them from an edge-only image.

Use a separate fixed-size texture view so that pixel offsets have a stable
meaning independent of the CNN input resolution:

| Parameter | Initial value |
| --- | --- |
| Texture-view size | `104 x 224` |
| Gray-level quantization | `32` levels |
| Distances | `1, 2, 3` pixels |
| Angles | `0`, `45`, `90`, `135` degrees |
| Matrix properties | symmetric and normalized |
| Aggregation | mean across all distance-angle matrices |

Extract exactly six features:

1. contrast;
2. dissimilarity;
3. homogeneity;
4. energy;
5. correlation;
6. angular second moment (ASM).

Fit feature means and standard deviations on the training partition only. Save
those statistics with the checkpoint and reuse them unchanged for validation,
holdout evaluation, and inference. Guard against zero-variance features and
non-finite correlation values.

The first experiment must not search texture sizes, gray levels, distances, or
angles. These values are predeclared to avoid converting the validation set into
a hidden hyperparameter test set.

## Explainable Fusion Design

Use separate class-logit contributions rather than opaque concatenation through
a large joint classifier:

```text
CNN feature maps -> CNN classifier -> cnn_logits
GLCM vector      -> small MLP       -> glcm_logits

final_logits = cnn_logits + alpha * glcm_logits
```

Initial branch design:

- input: six standardized features;
- hidden width: `16`;
- activation: ReLU;
- dropout: `0.20`;
- output: five GLCM class logits;
- initial `alpha`: one learned scalar constrained to `[0, 1]`;
- initialize `alpha` near zero so the experiment begins from the deep baseline.

The CNN CAM explains `cnn_logits`, not the complete fused prediction. Every
audit artifact must therefore record:

- CNN logits and probabilities;
- scaled GLCM logits;
- final fused logits and probabilities;
- the learned `alpha`;
- the fraction of the winning-class logit attributable to each branch.

Do not label the CNN heatmap as a complete explanation of the hybrid output. If
the GLCM branch changes the selected grade, flag the case explicitly in the CAM
audit.

## Checkpoint Selection

Use the existing validation-only predictive score:

```text
selection_score = 0.55 * QWK + 0.30 * macro_F1 + 0.15 * macro_AP
```

Apply localization and calibration constraints before ranking by this score. A
checkpoint that fails the constraints cannot win even if its predictive score
is higher.

## Predictive Evaluation

Report each seed separately and the paired aggregate across seeds:

- accuracy and balanced accuracy;
- QWK and mean absolute grade error;
- macro precision, recall, and F1;
- macro average precision and ROC AUC;
- per-grade precision, recall, F1, and AP;
- Grade-1 recall and Grade-4 recall;
- adjacent-grade error rate;
- under-grades and over-grades by two or more levels;
- negative log-likelihood, Brier score, and expected calibration error;
- confusion matrix and predicted-grade distribution.

Confidence intervals must respect patient clustering. Resample patients, not
individual knees, so bilateral images do not create falsely narrow intervals.

## CAM and Explanation Audit

Audit the same validation cases for both arms, targeting up to 50 patients per
grade where the split permits. Report overall and per-grade values for:

- joint energy and joint enrichment;
- border energy and border enrichment;
- lower-tibia energy;
- peak-inside-joint rate;
- anatomy-gate pass rate;
- joint occlusion probability drop;
- border occlusion probability drop;
- joint-minus-border occlusion contrast;
- CAM/occlusion Spearman correlation;
- horizontal-flip CAM consistency when anatomically appropriate.

Create a paired review set containing:

- cases correct in both arms;
- cases corrected by GLCM;
- cases broken by GLCM;
- cases where the predicted grade changes but CNN CAM geometry barely changes;
- cases where the GLCM contribution dominates the winning class;
- representative KL-1 and KL-4 cases.

Broad rectangular joint energy is an anatomy proxy, not a lesion annotation.
Clinical claims require reviewed joint-space, osteophyte, sclerosis, or deformity
annotations and must not be inferred from attractive overlays alone.

## Predeclared Acceptance Criteria

Promote the GLCM arm for locked-holdout evaluation only when all conditions are
met across the paired seed aggregate:

| Criterion | Required result |
| --- | --- |
| QWK | Mean improvement at least `0.01` over the control |
| Macro F1 | Mean improvement at least `0.01` over the control |
| Macro AP | No material regression; lower paired CI bound should not show a harmful drop |
| KL-1 recall | Decrease no greater than `0.03` |
| Severe errors | No increase in errors of two or more grades |
| Calibration | ECE increase no greater than `0.01` |
| CAM gate pass rate | Decrease less than `0.05` absolute |
| Joint occlusion evidence | No meaningful reduction in joint-minus-border contrast |
| Seed stability | Direction of QWK and macro-F1 change consistent across seeds |
| Branch dominance | No evidence that acquisition texture alone controls most decisions |

If GLCM improves accuracy but fails QWK, minority-grade, calibration, or CAM
constraints, reject it. If effects are smaller than the thresholds or unstable
across seeds, retain the simpler deep-only model.

## Locked-Holdout Policy

After all feature choices, thresholds, and the winning arm are frozen, evaluate
the selected candidate and its paired deep-only control once on a new locked,
patient-disjoint holdout. Report patient-clustered bootstrap confidence intervals
and do not make additional configuration changes from that result.

The existing repeatedly inspected test set may be retained for historical
provenance, but it must not support a new superiority claim.

## Execution Order

1. Complete and review the production-ROI robustness experiment.
2. Freeze the patient-disjoint split and production preprocessing manifest.
3. Precompute training-only GLCM normalization statistics.
4. Run paired control and GLCM arms for seed 1.
5. Perform an early implementation audit, not model selection, to confirm that
   feature scaling, branch logging, and CAM geometry are correct.
6. Run the remaining paired seeds without changing the specification.
7. Aggregate predictive, calibration, and CAM results.
8. Apply the predeclared acceptance criteria.
9. Evaluate once on a new locked holdout only if the GLCM arm qualifies.
10. Archive the complete notebook, outputs, checkpoint metadata, metrics,
    figures, and failure analysis under the repository reporting guidelines.

## Possible Follow-Up

Only after this experiment is resolved should later work consider an auxiliary
`(KL-0 + KL-1)` versus `KL-2+` screening head, a stride-16 CAM head, or revised
ensemble weights. Those are separate hypotheses and must not be folded into the
GLCM comparison.
